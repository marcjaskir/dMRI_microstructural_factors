# QSIRecon

## Purpose

Run QSIRecon reconstructors (DKI, NODDI, GQI, MAP-MRI, atlases).

## Entry points

run_qsirecon.sh, recon_spec_*.yaml

## Inputs

qsiprep, freesurfer

## Outputs

derivatives/qsirecon

## Configuration

Paths are resolved via [`config.yaml`](../config.example.yaml) and [`lib/paths.py`](../lib/paths.py).
