# Atlas utilities

Atlas construction, QC, and conversion helpers (Glasser, HCP1065, random atlases).

## Entry points

gen_glasser_atlas_centroids.py, trk_to_nii_HCP1065.py

## Inputs

data/atlases

## Outputs

data/atlases

## Configuration

Paths are resolved via [`config.yaml`](../config.example.yaml) and [`lib/paths.py`](../lib/paths.py).
