# Factor z-scores

## Purpose

Apply control loadings to produce patient/control factor scores and normative
factor **z-scores** (overall / non-Gaussian / anisotropic diffusivity).

## Entry points

`factor_z-scores.py`

## Inputs

`gam`, `factor_analysis`

## Outputs

`derivatives/analysis/factor_z-scores`

## Configuration

Paths are resolved via [`config.yaml`](../../config.example.yaml) and [`lib/paths.py`](../../lib/paths.py).
Labels: `lib/factor_labels.py`.
