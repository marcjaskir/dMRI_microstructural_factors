# Atlas centroids

## Purpose

Build unified MNI centroid tables (Glasser, 4S156, HCP1065 thirds) for gradient visualizations.

## Entry points

compute_atlas_centroids.py

## Inputs

data/atlases

## Outputs

derivatives/atlas_centroids

## Configuration

Paths are resolved via [`config.yaml`](../config.example.yaml) and [`lib/paths.py`](../lib/paths.py).
