# Imaging pipeline

End-to-end flow from raw data to GAM-adjusted microstructural features.

Cohort-specific ingress differs before the shared tractography path:

- **Penn + HCP-Aging:** BIDS → qsiprep → freesurfer → qsirecon
- **HCP-YA:** → qsirecon (skip qsiprep/freesurfer; use existing HCP derivatives)

```
Penn / HCP-Aging:  BIDS  →  qsiprep  →  freesurfer  →  qsirecon
HCP-YA:                                     →  qsirecon
                              ↓
                         acpc_mni_xfm
                              ↓
              trekker  →  bundleseg  →  pyafq / mni_micro
                              ↓
                    [Tier 2] covbat  →  gam
                              ↓
                         [Tier 1 open products]
              factor_analysis  →  factor_z-scores  →  gradients
                              ↓
         tract/region asymmetry  →  microstructural asymmetry reports
```

HCP Young Adult / Aging BIDS conversion uses
[HCPLifespan2BIDS](https://github.com/ellisdg/HCPLifespan2BIDS) (not vendored here).

## Stage 0: Data ingress

| Module | Purpose | Entry points |
|--------|---------|--------------|
| [bids](../bids/) | Link Penn BIDS; HCP Lifespan conversion via [HCPLifespan2BIDS](https://github.com/ellisdg/HCPLifespan2BIDS) | `link_bids_penn.sh`, `add_topup_intended_for_penn.py` |

Controlled demographics/scanner tables live under `data/controlled/` (not generated by shipped scripts in this repo).

## Stage 1: Preprocessing and reconstruction

| Module | Purpose | Entry points |
|--------|---------|--------------|
| [qsiprep](../qsiprep/) | QSIPrep container preprocessing (Penn / HCP-Aging) | `run_qsiprep.sh` → `qsiprep.sh` |
| [freesurfer](../freesurfer/) | FreeSurfer recon-all from QSIPrep T1 | `run_recon_all.sh`, `recon_all.sh` |
| [qsirecon](../qsirecon/) | QSIRecon microstructural maps | `run_qsirecon.sh`, `recon_spec.yaml`, `recon_spec_custom_penn.yaml`, `recon_spec_custom_hcpaging.yaml` |
| [acpc_mni_xfm](../acpc_mni_xfm/) | ACPC↔MNI transforms for BundleSeg | `get_acpc_mni_affine.sh` |

## Stage 2: Tractography and segmentation

| Module | Purpose | Entry points |
|--------|---------|--------------|
| [trekker](../trekker/) | Whole-brain Trekker tracking | `run_trekker.sh` → `trekker.sh` |
| [bundleseg](../bundleseg/) | BundleSeg tract segmentation | `wrapper_run_bundleseg.sh`, `run_bundleseg.py` |
| [atlases](../atlases/) | Atlas construction and QC helpers | `gen_glasser_atlas_centroids.py`, `trk_to_nii_HCP1065.py` |
| [atlas_centroids](../atlas_centroids/) | Build unified MNI centroid tables (Glasser, 4S156, HCP1065 thirds) for gradient visualizations and comparison with neuroanatomical axes | `compute_atlas_centroids.py` |
| [centroid_coordinates](../centroid_coordinates/) | Node-wise streamline centroids | `centroid_coordinates.py` |

## Stage 3: Along-tract and region microstructure

| Module | Purpose | Entry points |
|--------|---------|--------------|
| [pyafq](../pyafq/) | Along-tract scalar profiling (HCP1065) | `run_pyafq.sh` → `pyafq.py` |
| [mni_micro](../mni_micro/) | Region/tract MNI-space scalar means (HDF5) | `mni_atlas_micro.py` |

## Stage 4: Harmonization and normative modeling

| Module | Purpose | Entry points |
|--------|---------|--------------|
| [covbat](../covbat/) | CovBat batch correction (pyAFQ + mni_micro) | `prep_pyafq_covbat.py`, `covbat_pyafq_nodewise.R` |
| [gam](../gam/) | Age/sex GAMs; residual z-scores | `gam_pyafq.R`, `gam_mni_micro.R` |

## Dependencies

Singularity images for QSIPrep, QSIRecon, and Trekker are **not** included. Document local image paths in your site config or environment. See root [`environment.yml`](../../environment.yml) for Python/R packages used by shipped scripts.

## Config keys used

- `workspace_root`, `code_dir`, `data_open_dir`, `data_controlled_dir`
- `gam_dir`, `analysis_dir`, `atlas_dir`, `inclusion_dir`
- `controlled_derivatives_dir`, `controlled_metadata_dir`
- site-specific: `penn_bids_dir`, `freesurfer_image`, `singularity_tmpdir`
